Ilagay ang shortcut ng .bat file sa Startup folder ng Windows (Win+R -> shell:startup)
para kusang bumukas pagkatapos mag-restart ang computer.
 - start_kiosk.bat        : computer ng kiosk (kumukuha ng ticket, direkta sa printer)
 - start_now_serving.bat  : TV / monitor ng Now Serving (may tunog agad)
Kung galing sa ibang computer ang kiosk, palitan ang "localhost" ng IP address ng server.
